    Arm the daily digest

    A fit-aware digest of fresh good-or-better matches, pushed to your phone at 08:00 via ntfy.sh. It runs on this machine — your résumé profile never enters CI.

    1. Create the env file, then set NTFY_TOPIC to a private topic (optionally SUPABASE_URL/SUPABASE_SERVICE_KEY for live data):

      cp radar/scripts/.digest.env.example radar/scripts/.digest.env

    2. Load the launch agent (daily 08:00; the plist header carries the same commands):

      cp radar/scripts/com.veritas.radar.digest.plist ~/Library/LaunchAgents/ && launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.veritas.radar.digest.plist

    3. Subscribe to ntfy.sh/<your topic> on your phone. Optional: also set NTFY_TOPIC as a repo secret so the CI fallback digest pushes — the local one above is the fit-aware one.

    Dry-run any time: npm run radar:digest:local -- --dry-run
